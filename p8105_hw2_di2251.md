**Data-set description:** This data-set contains information related to
each entrance and exit for each subway station in New York City. As a
part of the initial data cleaning, the variable names of the imported
data were automatically reformatted to a standardized format. The 19
variables or columns relevant to the problem were selected out of the 32
total variables (columns) in the original data-set. These selected
variables contain information on the subway line, station name, station
latitude/longitude, route number, entry, vending, entrance type, and ADA
compliance. There are a total of 1,868 rows or observations in the
data-set. In addition, the entry variable was converted from a character
variable of `YES` vs `NO` to a logical variable. However, this data is
not tidy since the lines that run or do not run through each of routes 1
to 11 are independently displayed the information can be collapsed into
a character variable listing which lines travel along which routes
rather than having them all listed separately.
