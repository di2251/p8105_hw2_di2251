This dataset contains information related to each entrance and exit for
each subway station in New York City. As a part of the initial data
cleaning, the variable names of the imported data were reformatted to
snake case and `NA` coding was standardize across variables.

The 19 variables relevant to the problem were selected out of the 32
total variables (columns) in the original dataset. These selected
variables contain information on the subway line, station name, station
latitude/longitude, route number, entry, vending, entrance type, and ADA
compliance. There are a total of 1868 observations in the dataset. In
addition, the entry variable was converted from a character variable of
`YES` vs `NO` to a logical variable.

However, this data is not tidy since the lines that run or do not run
through each of routes 1 to 11 are independently displayed the
information can be collapsed into a character variable listing which
lines travel along which routes rather than having them all listed
separately.

#### Combine and export

``` r
MCI_combined = inner_join(MCI_baseline, MCI_amyloid, by = "id")

```

The amyloid dataset contains 487 participants, each with amyloid β 42/40
ratio measurements at baseline and up to four follow-up visits. As with
the baseline file, the first row contained variable descriptions and was
skipped. the ID column was renamed to `id` to match the baseline data,
and the measurements, which were originally spread across one column per
visit, were pivoted into long format so each row represents one
participant at one time point. The tidy dataset has 2435 rows and 172
missing amyloid values.

8 participants appear only in the baseline data, and 16 participants
appear only in the amyloid data. After combining the datasets to keep
only participants in both, the resulting dataset contains 471
participants and 2355 rows, with 8 variables.
